# PRJNA990964

Arabidopsis thaliana matched Ribo-seq and RNA-seq dataset.

## Study

BioProject: PRJNA990964

## Organism

Arabidopsis thaliana

## Selected samples

This project uses only shoot samples.

Included:

- RNA-seq (4 biological replicates)
- Ribo-seq (4 biological replicates)

Root samples and mapping-derived runs are intentionally excluded.

## Files

- `RunInfo.csv`
  - Original NCBI run table.

- `shoot.tsv`
  - Curated shoot-only experimental design.

- `shoot_srr.txt`
  - List of SRR accessions used for download.
